# CRM 模块数据库迁移

命名约定：`{序号}_{版本号}_{描述}.sql`

ModuleLoader 启动时按序号顺序自动执行未跑过的 SQL，执行记录写入 `yoshop_skill_migration` 表。

## 注意：同一模块内版本号必须唯一

ModuleLoader 用 `(skill_name, version)` 判断是否已执行，**不是文件名**。
两个文件写同一个版本号时，第一个执行后第二个会被直接跳过（2026-11-18 踩过：047/048 都写 2.14.0，048 没执行）。

规则：

- 一个文件一个版本号，且该版本号在本模块历史中不能出现过
- 同一批功能拆多个文件时，用递增版本号（如 2.14.0 / 2.14.1）
- 文件名里的版本号会写进 `yoshop_skill_migration.version`（varchar 20），不要写超长前缀
